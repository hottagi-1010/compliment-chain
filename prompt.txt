아래와 같이 팀 칭찬 릴레이 게시판 웹앱을 만들어줘. 

1. 목적 : 동료에게 고마운 일을 짧게 남기면 모두가 함께 보는 게시판
2. 사용자 : 직원 동료
3. 기능목록
  • 필수 기능
    ◦ 받는 사람, 보내는 사람(닉네임 가능), 칭찬 내용을 입력하는 폼
    ◦ "남기기" 버튼을 누르면 Supabase 테이블에 저장
    ◦ 저장된 칭찬을 최신순 카드 목록으로 보여주기
 • 부가 기능
    ◦ 하트(좋아요) 버튼과 개수 표시
    ◦ 받는 사람 이름으로 검색
    ◦ 이번 달 칭찬 많이 받은 사람 순위

4. 작업절차 
 - 데이터는 Supabase에 저장하고 Vercel로 배포할 거야. 
 - 먼저 Supabase SQL Editor에서 실행할 praises 테이블(받는 사람, 보내는 사람, 내용, 작성 시각) 생성 SQL을 알려주고, RLS를 켠 뒤 누구나 읽고 쓸 수 있는 정책도 함께 만들어줘. 
  * 테이블 예시: praises (id, to_name, from_name, message, created_at)

 - 화면은 입력 폼과 최신순 카드 목록으로 구성해줘. 
 - Supabase 주소와 키는 환경변수로 불러오게 해줘.
